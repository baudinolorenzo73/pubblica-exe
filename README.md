# Pubblica 1.0

App HTML trasformata in programma per Windows: si apre in una finestra con il motore di Edge (WebView2).

- Le pagine sono in `progetto/` (si apre `index.html`); `avvia_app.py` le serve da un piccolo server locale.
- I dati salvati dall'app restano in `%LOCALAPPDATA%\by Lollo\Pubblica`.
- L'EXE pronto è nelle **Releases** del repository.
